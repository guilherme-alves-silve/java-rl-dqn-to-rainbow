Interactive diagram of SumSegmentTree: structure and operations update, rangeSum and sampleIndexByValue

Binary tree of recursive nodes. Each node stores sum = sum of leaves in interval [leftMost, rightMost]. Built in O(n). Example with size=4.

update(idx=2, value=0.8) — descends via mid=(l+r)/2: idx≤mid → left, else right. Updates the leaf, then propagates the sum back up (bottom-up).

rangeSum(start=1, end=3) — 3 cases per node: out of range → 0; fully covered → return sum; partial → recurse into children.

sampleIndexByValue(sample=0.55) — navigates the tree using cumulative sums. If sample ≤ left.sum → go left; else go right subtracting left.sum. Core of proportional PER sampling.
